# DIEGO — Decentralized Immutable Evidence for Generated Output

> On-chain notarization for AI-generated content. Prove who created it. Prove when. Anytime. 

**Live app:** [diego-frontend.vercel.app](https://diego-frontend.vercel.app)  
**Smart contract:** [0x47F5E1AebF5D5558f1c3b1f6Aa2dbc2a10E3d879](https://sepolia.etherscan.io/address/0x47F5E1AebF5D5558f1c3b1f6Aa2dbc2a10E3d879#code) on Ethereum Sepolia

## What is DIEGO?

AI-generated content has an authorship problem. Anyone can copy an essay, a piece of code, or an analysis generated by Claude and claim they wrote it — or say it was created at a different time. Screenshots can be faked. Emails can be edited. There's no trusted, open system to prove provenance. 

DIEGO solves this by combining three things:

1. **Claude API** — generates text from a user prompt
2. **SHA-256 hashing** — turns that text into a unique 64-character fingerprint in the browser
3. **Ethereum smart contract** — records that fingerprint permanently on the blockchain with your wallet address and a timestamp

The result is an immutable, public, trustless record of who created a piece of AI content and when. No company controls it. No one can edit or delete it.

## Features

- **Generate** — Prompt Claude to create AI content directly in the app
- **Notarize** — Hash the output with SHA-256 and write it to Ethereum via MetaMask
- **Verify** — Anyone can paste text and check if it's been notarized — no wallet needed, free
- **Dashboard** — Connected wallet's full notarization history pulled live from blockchain events
- **Live feed** — Real-time blockchain events from the contract, polling every 30 seconds
- **Animated hash ticker** — Hero section displays your most recent real on-chain hash

## How It Works

```
User types prompt
      ↓
Claude API generates text (via Vercel serverless function)
      ↓
Web Crypto API hashes the text with SHA-256 in the browser
      ↓
ethers.js sends the hash to ProvenanceRegistry.sol
      ↓
MetaMask signs the transaction
      ↓
Hash + wallet address + timestamp stored permanently on Ethereum
      ↓
Etherscan receipt shown to user
```

## Smart Contract

`ProvenanceRegistry.sol` is deployed and Etherscan-verified at:

```
0x47F5E1AebF5D5558f1c3b1f6Aa2dbc2a10E3d879
```

[View on Etherscan ↗](https://sepolia.etherscan.io/address/0x47F5E1AebF5D5558f1c3b1f6Aa2dbc2a10E3d879#code)

### Key design decisions

- **`bytes32` hash as primary key** — SHA-256 is always 32 bytes, mapping perfectly to a single EVM storage slot. Cheaper than storing as a string.
- **First write wins** — duplicate hashes revert with a custom `HashAlreadyRecorded` error. Whoever submits first holds the provenance record permanently.
- **Free verification** — `verify()` and `isRecorded()` are `view` functions. Zero gas to query. Anyone can check anytime.
- **Indexed events** — `ContentNotarized` is indexed by hash and wallet, making off-chain lookups via Etherscan fast.
- **Custom errors** — cheaper than `require` strings; encodes only a 4-byte selector instead of a full string in bytecode.

## Running Locally

### Prerequisites

- Node.js v20+
- MetaMask or Phantom browser extension
- Sepolia testnet ETH (free from [sepoliafaucet.com](https://sepoliafaucet.com))

### 1. Clone the repo

```bash
git clone https://github.com/DiegoCarpenter/ai-provenance.git
cd ai-provenance
```

### 2. Set up the frontend

```bash
cd frontend
npm install
```

Create `frontend/.env` with your keys:

```
VITE_CONTRACT_ADDRESS=0x47F5E1AebF5D5558f1c3b1f6Aa2dbc2a10E3d879
VITE_WALLETCONNECT_PROJECT_ID=your_walletconnect_project_id
VITE_ALCHEMY_KEY=your_alchemy_api_key
ANTHROPIC_API_KEY=your_anthropic_api_key
```

### 3. Run locally

```bash
npx vercel dev
```

Open [localhost:3000](http://localhost:3000)

> **Note:** Use `npx vercel dev` not `npm run dev` — the Claude API serverless function only works through Vercel's dev server.

### 4. Set up the contract (optional — already deployed)

```bash
cd contract
npm install
```

Create `contract/.env`:

```
SEPOLIA_RPC_URL=https://eth-sepolia.g.alchemy.com/v2/your_key
PRIVATE_KEY=your_wallet_private_key
ETHERSCAN_API_KEY=your_etherscan_key
```

Run tests:

```bash
npx hardhat test
```

Deploy:

```bash
npx hardhat run scripts/deploy.js --network sepolia
npx hardhat verify --network sepolia DEPLOYED_ADDRESS
```

## Why Ethereum?

Any centralized database can be edited, taken down, or controlled by whoever owns the server. Ethereum provides a guarantee that no database can — once a hash is written, nobody (including the contract deployer) can change or delete it. The record is enforced mathematically by thousands of nodes simultaneously.
